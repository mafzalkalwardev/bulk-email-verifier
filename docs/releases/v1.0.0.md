# v1.0.0

Self-hosted email verification. Node.js UI, truemail-go, optional Reacher.

## Run

```bash
docker compose up --build
```

Or, with Node.js 18+ and Go 1.22+:

```bash
cp .env.example .env
npm install
npm start
```

Open http://localhost:5000

## Free mode

No license file is required.

- Single-address checks are not capped.
- Bulk checks are limited to 25 addresses per account per UTC day.
- A verified `indus-license*.json` file removes the bulk cap.

## Included

- Single verify and bulk CSV/XLSX (email in any column)
- Valid-only CSV export and browser-session resume for a bulk job
- Local accounts, validation history, light/dark theme
- truemail-go for syntax, MX, and SMTP. Reacher is a compose profile, not the default.

## Responsible use

Permission-based email verification only. No spam or phishing.
