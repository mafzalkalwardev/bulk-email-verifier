# v1.0.0 — Initial Stable Release

Self-hosted bulk email verification with Node.js UI, truemail-go, and optional Reacher Docker engine.

## Highlights

- Single and bulk CSV/XLSX verification
- JWT auth, dark mode, valid-only export
- Correct clone instructions and compliance section
- Docker optional for Gmail-safe checks

## Install

```bash
git clone https://github.com/mafzalkalwardev/bulk-email-verifier.git
cd bulk-email-verifier
cp .env.example .env
npm install
npm start
```

Open http://localhost:5000

## Responsible use

Permission-based email verification only. No spam or phishing.
